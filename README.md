# Мои Финансы

Мобильное Android-приложение на основе последней веб-версии v4.

Ежедневно можно ввести доход и фактический пробег. Приложение распределяет деньги на жизнь, бензин, резерв автомобиля и выбранный план: инвестиции или вклад. История расчётов хранится локально.

APK собирается GitHub Actions обычным Android Gradle Plugin/Gradle toolchain.
